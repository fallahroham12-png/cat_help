راهنمای این پوشه
==================
index.html  -> ساختار صفحه
style.css   -> استایل و رنگ‌ها
script.js   -> تنظیمات قابل‌ویرایش (نام گربه، مبالغ، شماره کارت، تماس) + منطق صفحه
images/     -> عکس‌های واقعی را با همین نام‌ها اینجا بگذارید تا جای Placeholder بنشینند:
              cat-main.jpg, cat-1.jpg, cat-2.jpg, xray-1.jpg, doc-1.jpg,
              invoice-1.jpg, before-1.jpg, after-1.jpg, progress-1.jpg, payment-qr.png

برای انتشار: کل این پوشه را در یک ریپازیتوری گیت‌هاب قرار داده و
GitHub Pages (یا Cloudflare Pages) را روی آن فعال کنید.
سپس QR Code خود را طوری بسازید که به آدرس همان صفحهٔ منتشرشده لینک شود.
